# Learn the resolution problem

Begin with the [explanatory report (PDF)](report/Markovian_Resolution_Limit_Report.pdf) for a continuous account from quantum states and open-system dynamics to the intervention law and the original sensing results. This published snapshot includes worked examples and an exact echo diagram. The [current timing account](../science/hidden_jitter_precision.md) gives the matching minimax law with a limited number of jittered pulses.

Both sister projects use **Rivas and Huelga, _Open Quantum Systems: An Introduction_, arXiv:1104.5242v2**, as their single common educational anchor. The [source bridge](ANCHOR.md) identifies the relevant sections and translates their conventions. Reading the whole source first is unnecessary.

The tutorial develops selected examples. The scientific pages give the current statements, proofs and attribution. The sister repository develops the shared recorded-phase method, which the ideal and known-displacement settings use. This repository also gives the signed parity calculation and phase inversion needed when the timing sign is hidden.

The report's editable source and compilation instructions are in the [technical build guide](../verification/README.md#explanatory-report-build).
